Quick Start

From import to a puzzle you can play, in about five minutes.

On this page

  • 1. Install
  • 2. Generate a puzzle
  • 3. Read the analysis

  • 5. Play the demo

1. Install

Import the package. Everything lives under Assets/SimpleConveyor/, and nothing is added to your scenes until you ask for it.

The core (the generator, the solver, the play rules and the puzzle data) has no package dependencies. The demo uses the Input System and Unity UI packages. It reads the mouse, touch and keyboard through the Input System, so set Project Settings > Player > Active Input Handling to Input System Package or Both before you play it.

Render pipelines: URP is recommended, HDRP is supported and the Built-in pipeline still works. The demo builds its materials from the active pipeline's default shader and keeps that shader in your builds, and on HDRP it adds a small volume so it looks the same as on the others (turn off HdrpLook on the ConveyorDemo component to use your own lighting instead). Simple Conveyor was built and tested with Unity 6000.6.

2. Generate a puzzle

Open Window > Living Failure > Simple Conveyor > Conveyor Generator. You can also get there from Assets > Create > Simple Conveyor > Conveyor Generator.

1

Take a preset

Press Presets and pick Belts/First puzzle: a 5 x 5 board of belts and stop tiles with a par of 6 or 7. A preset replaces every setting with a ready-made recipe.

2

Generate

Press Generate. Puzzles are built and solved on a background thread, so the window stays responsive, and a long batch shows a progress bar with a Cancel button. Raise Batch count to make up to 50 at a time.

3

Try a few more

Switches/Reverse adds 2 switches that make the switched belts run the other way. Gems/Small adds a gem to take before the goal counts. Holes/Medium lays ice with 3 holes an ice slide can carry the piece into, and Chest spots/Belts keeps at least 6 resting places off the best route for chests or keys.

If you change settings by hand and they fight each other (holes without ice, a par window the stop tiles can never give, more chest spots than the board can hold, or a par window the target stars can never meet), the window warns you, and Auto fixes them and tells you what it changed.

3. Read the analysis

The pane on the right shows the selected puzzle. From the top:

  • The verdict: the par in moves (and "one best solution" when there is just one) and the difficulty out of 5, with a line that sums up the board and its seed. A warning shows when the piece can get stuck.
  • Board: a picture of the puzzle with a Move slider above it that steps through the best solution, and Play to watch it move by move. The piece rides, gems go, switched belts turn and the moves so far are drawn as a line. Hover a cell to read it, and zoom in on a big board. Chest spots marks every resting place off the best route with the extra moves going by it costs.
  • On this board: beside the picture, a plain-words list of what the board holds.
  • Export: save the puzzle as a PNG or SVG, as the colour view, a printable sheet or an answer key.
  • Best solution: every move written out, with a Copy solution button.
  • Facts and Generation report: the numbers (resting places, choices, decoys, wrong turns, chest spots and more) and every note the generator left.

Pressing Play is the quickest way to judge a puzzle. You can see where each ride ends and how the belts carry the piece round the board to reach the goal.

4. Save it

Press Save and choose:

  • Current saves the selected puzzle as a ConveyorPuzzleAsset.
  • Pack (all) saves every puzzle in the set as one ordered ConveyorPuzzlePack.
  • Pack (on target only) leaves out the fallbacks, the puzzles that missed something their settings asked for.

Both asset types have inspectors with the same analysis pane, plus Verify, which solves the puzzle again and refreshes its stored verdict, and Re-roll, which builds a new puzzle from the same settings with a fresh seed. A pack can also re-roll just its fallbacks, and Export all writes every puzzle and its answer key into a folder you pick.

5. Play the demo

Open Assets/SimpleConveyor/Scenes/SimpleConveyorDemo.unity and press Play. The demo opens on a welcome screen. Press Let's play, pick a mode, then choose Endless for a new puzzle to your order or Level Pack for the ready-made levels.

The controls are also listed at the bottom of the screen while you play:

  • Arrow keys or WASD move the puck, and so does a swipe. A tap beside the puck moves it toward the tap. Each key moves the way that looks closest to it on screen, so the controls stay right however the camera is turned.
  • U (or Backspace, or Ctrl+Z) undoes a move, R restarts and H shows a hint.
  • F lets the solver play the rest of the puzzle from where you are, and F or R stops it.
  • [ and ] turn the camera, Home and End tilt it, the mouse wheel or + and - zoom, and right-drag turns and tilts. V resets the view.
  • M mutes the sound and Esc goes back to the menu.

The same actions are on the buttons at the bottom: Undo, Restart, Hint, Solve and Menu. A ride into a hole plays out, the puck drops in, and then it goes back where it was. A fall isn't counted as a move.

6. Use it in your game

Make a puzzle in code, check what the solver found, and read the rest straight off the ConveyorData:

using SimpleConveyor;

var settings = new ConveyorSettings
{
    Width = 8, Height = 8,
    Pickups = 1,                 // a gem to take before the goal counts
    TargetDifficulty = 3,        // keep trying seeds until it rates 3 stars
};
ConveyorData puzzle = ConveyorGenerator.GenerateVerified(settings);
Debug.Log($"Par {puzzle.Par} moves, {puzzle.Difficulty} stars, solvable: {puzzle.Solvable}");

To run your own game on it, keep a ConveyorPlay and ask ConveyorRules what each move does. These are the same rules the solver used, so your game always agrees with the par:

ConveyorPlay play = ConveyorRules.NewGame(puzzle);
if (ConveyorRules.TryMove(puzzle, play, 1, out string reason))   // 0 north, 1 east, 2 south, 3 west
{
    if (play.Lost) Debug.Log("Into a hole!");
    else if (ConveyorRules.IsSolved(puzzle, play)) Debug.Log("Solved!");
}
else Debug.Log(reason);                                           // why not: a wall or the edge right next to the piece

if (ConveyorRules.Hint(puzzle, play, out int dir))
    Debug.Log($"A best move from here: {dir}. {ConveyorRules.PickupsLeft(puzzle, play)} gems left.");

The core numbers cells from the bottom left, row by row (y * Width + x), and names them by what they do (see Names in the data), so a refused move's reason reads like "an Obstacle stands on 23, right next to the piece". Another overload of TryMove also lists every cell the ride passes through, for a game to animate. The demo turns all of this into words and motion for players.

Or let the demo's 3D view draw and play it for you. ConveyorGame adds a ConveyorBoardView to the same object and builds the whole board from code:

using SimpleConveyor.Demo;

var game = new GameObject("Conveyor").AddComponent<ConveyorGame>();
game.Begin(puzzle);
game.View.FrameCamera(Camera.main);

A saved puzzle works the same way: give your script a ConveyorPuzzleAsset field and use its Puzzle, or a ConveyorPuzzlePack and its Get(index). See the API Reference for the rest.
